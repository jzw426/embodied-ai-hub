环境安装避坑指南

Windows 环境下的一键安装命令与常见问题

🐍 Python 环境（推荐 3.10+）

1. 下载安装
官网下载 Python 3.10 或更高版本，安装时务必勾选 "Add Python to PATH"。
python --version pip --version
避坑：如果提示 "python 不是内部或外部命令"，说明安装时没勾 PATH，重新运行安装程序选 Modify 补上即可。

📦 虚拟环境（强烈建议）

创建并激活 venv
python -m venv venv venv\Scripts\activate
为什么要建：不同项目依赖版本会冲突，虚拟环境能隔离。激活后命令行前面会出现 (venv)。

🏋️ Gymnasium（强化学习环境）

安装命令
pip install gymnasium pip install "gymnasium[classic-control]"
避坑：旧教程里的 OpenAI Gym 已停更，现在统一用 Gymnasium（Farama 基金会维护）。CartPole 属于 classic-control 模块，必须额外装。

🦾 PyBullet（机器人仿真）

安装命令
pip install pybullet pip install numpy matplotlib
避坑：Windows 上首次运行会下载额外资源，耐心等 1-2 分钟。如果报错，先升级 pip：python -m pip install --upgrade pip。

🔌 requests（API 调用）

安装命令
pip install requests pip install aiohttp
说明：requests 用于同步调用，aiohttp 用于第 2 周的异步并发调用。

✅ 一键验证全部安装

复制下面这段代码保存为 check_env.py，运行即可
import sys print(f"Python 版本: {sys.version}") try: import requests; print(f"✓ requests {requests.__version__}") except: print("✗ requests 未安装") try: import gymnasium; print(f"✓ gymnasium {gymnasium.__version__}") except: print("✗ gymnasium 未安装") try: import pybullet; print("✓ pybullet 已安装") except: print("✗ pybullet 未安装") try: import numpy; print(f"✓ numpy {numpy.__version__}") except: print("✗ numpy 未安装") print("\n全部通过就可以开始学习了！")
用法：把上面代码复制到记事本，存为 check_env.py，然后在命令行运行 python check_env.py，绿勾越多环境越全。

常见报错急救包

零基础最容易踩的坑，遇到直接查，不用去搜半天

'python' 不是内部或外部命令
原因：安装 Python 时没勾 "Add Python to PATH"
解决：① 重新运行安装包 → Modify → 勾选 Add to PATH；② 或者手动把 Python 安装目录加到系统环境变量 PATH
ModuleNotFoundError: No module named 'xxx'
原因：没装这个库，或者装在了别的虚拟环境里
解决：① 先确认 venv 已激活（命令行前面有 (venv)）；② pip install xxx；③ 还不行就 pip install --upgrade pip 再试
pip 安装超时 / 下载慢
原因：默认源在国外，国内访问慢
解决：换清华源：pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple
CartPole 跑不起来 / No module named 'gym'
原因：老教程用的是 OpenAI Gym，现在已停更
解决：pip install gymnasium "gymnasium[classic-control]"，代码里 import gymnasium as gym
PyBullet 安装报错 / 运行卡住
原因：Windows 首次运行要下载额外资源，pip 版本太低
解决：① python -m pip install --upgrade pip；② pip install pybullet；③ 运行时等 1-2 分钟别关窗口
JSON 解析报错 / JSONDecodeError
原因：API 返回的不是 JSON，可能是 HTML 错误页
解决：先 print(response.status_code) 和 print(response.text[:200]) 看看返回了啥，大概率是 URL 拼错了或 API 挂了
API 调用 401 Unauthorized
原因：需要 API Key，但你没传或者传错了
解决：检查请求头里的 Authorization 字段，确认 Key 没过期、没多空格
中文乱码 / UnicodeDecodeError
原因：Windows 默认编码不是 UTF-8
解决：open() 函数加 encoding='utf-8'：open('file.txt', 'r', encoding='utf-8')

术语速查表

遇到陌生名词不用搜，一句话看懂

State（状态）机器人当前所处的环境描述，比如小车位置、杆子角度
Action（动作）机器人能做的操作，比如"向左推"、"向右推"
Reward（奖励）做完动作后环境给的反馈，加分还是扣分，强化学习的目标就是拿更多分
Episode（回合）一局游戏，从开始到结束（比如杆子倒了就结束）
Policy（策略）机器人的"大脑"，决定看到什么状态该做什么动作
MDP（马尔可夫决策过程）强化学习的数学框架，简单说就是"状态→动作→奖励→新状态"的循环
Q-learning一种经典强化学习算法，学习每个状态下每个动作的"价值"，选价值最高的
LLM（大语言模型）GPT、DeepSeek、通义千问这类AI，能听懂自然语言指令
API（接口）不同程序之间互相调用的通道，比如你的Python代码调天气网站拿数据
RESTful一种API设计风格，用URL表示资源，用GET/POST表示操作
仿真环境在电脑里模拟真实物理世界，不用真机器人也能训练算法
具身智能AI有了"身体"，能在真实或仿真环境里通过交互学习，而不只是聊天

🌤️ 调天气 API 模板

import requests

url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 28.68,   # 南昌纬度
    "longitude": 115.86, # 南昌经度
    "current_weather": True
}

resp = requests.get(url, params=params)
data = resp.json()

print(f"当前温度：{data['current_weather']['temperature']}°C")
print(f"风速：{data['current_weather']['windspeed']} km/h")
第1周项目直接用这个，改城市坐标就行

📨 调 LLM API 模板（DeepSeek 为例）

import requests

url = "https://api.deepseek.com/v1/chat/completions"
headers = {
    "Authorization": "Bearer 你的API_KEY",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-chat",
    "messages": [
        {"role": "user", "content": "让机械臂往左移动，用JSON返回：{\"action\":\"left\",\"speed\":0.5}"}
    ]
}

resp = requests.post(url, headers=headers, json=data)
result = resp.json()
print(result["choices"][0]["message"]["content"])
第4周核心，把API_KEY换成你自己的

🎮 CartPole 随机策略模板

import gymnasium as gym

env = gym.make("CartPole-v1")
obs, info = env.reset()

for step in range(200):
    env.render()
    action = env.action_space.sample()  # 随机瞎选
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        print(f"撑了 {step} 步")
        break

env.close()
第3周入门先跑这个，看杆子能撑多久
